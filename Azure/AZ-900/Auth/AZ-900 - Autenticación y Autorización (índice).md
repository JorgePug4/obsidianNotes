> [!warning] Cambios de nombre que sí evalúa el examen
> Microsoft renombró toda la familia de identidad en 2023. En el examen actual verás los nombres nuevos:
> - **Azure Active Directory (Azure AD)** → **Microsoft Entra ID**
> - **Azure AD Domain Services** → **Microsoft Entra Domain Services**
> - **Azure AD Connect** → **Microsoft Entra Connect**
> - **Azure AD B2B / B2C** → **Microsoft Entra External ID**
>
> Si una pregunta usa el nombre viejo, trátalo como sinónimo. Lo que NO cambió: Active Directory Domain Services (AD DS) sigue siendo el AD local de Windows Server.
