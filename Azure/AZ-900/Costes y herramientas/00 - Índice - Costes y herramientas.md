# AZ-900 · Costes y herramientas de administración (Índice)

> [!important] Peso en el examen
> Este módulo completa el dominio **"Describir la administración y gobernanza de Azure" (30–35 %)** junto con [[00 Indice - Monitorizacion y Gestion|Monitorización y gestión]]. Cubre dos objetivos oficiales: **administración de costes** y **herramientas para implementar y administrar recursos**. Son preguntas de "qué herramienta uso para…", nunca de sintaxis.

## Qué evalúa el temario oficial

> [!info] Objetivos oficiales
> - **Administración de costes**: describir los factores que pueden afectar a los costes en Azure; comparar la calculadora de precios y la calculadora de TCO; describir Microsoft Cost Management; describir el propósito de las etiquetas.
> - **Herramientas para administrar e implementar recursos**: describir el portal de Azure, Azure Cloud Shell, la CLI de Azure y Azure PowerShell; describir el propósito de Azure Arc; describir la infraestructura como código (IaC); describir las plantillas de Azure Resource Manager (ARM).

> [!tip] Cómo estudiar esta sección
> Tres parejas concentran las preguntas: **calculadora de precios vs TCO**, **Cost Management vs Advisor** y **CLI vs PowerShell vs Cloud Shell**. Aprende qué pregunta responde cada herramienta y descarta el resto.

- [[Azure Arc]] extiende las herramientas de gestión a servidores fuera de Azure.
